# DevScope
Vous travaillez en tant que développeur front-end chez « DevScope », une jeune startup de recrutement tech. Les recruteurs perdent du temps à chercher des développeurs un par un sur GitHub et à noter leurs candidats dans des fichiers dispersés.

Votre mission : développer une application web qui récupère les profils et les dépôts publics depuis l'API GitHub, puis permet de gérer une shortlist de candidats enregistrée sur une API REST (MockAPI).

## Technologies
- HTML5 sémantique
- Tailwind CSS
- JavaScript (DOM, ES6)
- API REST (MockAPI)
- Git et GitHub (branches, Pull Requests)
- Atlassian Jira (planification)
